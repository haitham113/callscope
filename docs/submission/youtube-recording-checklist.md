# Public YouTube recording checklist

## Before recording

- [ ] Confirm the deployed HTTPS URL returns CallScope, not a 404 or stale bundle.
- [ ] Use the supported WebMCP-enabled Chrome configuration and confirm exactly seven tools are discoverable.
- [ ] Set the browser zoom to 100% and use at least a 1280×720 capture area.
- [ ] Close private tabs, notifications, bookmarks, profile details, terminals, and any secret-bearing windows.
- [ ] Run the complete validation suite and three rehearsal passes on the deployed origin.
- [ ] Open a fresh page and confirm the clean empty state, WebMCP readiness, and Start action.
- [ ] Keep the exact 2:30 script and two prompts available off-screen.
- [ ] Test microphone level, cursor visibility, and 1080p recording output.

## During recording

- [ ] Start on the deployed URL and identify it briefly.
- [ ] Show the one-click generated call reaching Healthy.
- [ ] Show `Audio live · disabled` after the real fault.
- [ ] Keep the User/Agent/System timeline and exact tool names visible.
- [ ] Show evidence, risk, reversibility, expiry, and the approval-only explanation.
- [ ] After approval, visibly prove that health is still Critical and audio is still disabled.
- [ ] Send the exact second prompt before the apply call.
- [ ] Show the before/after verdict and sanitized incident report.
- [ ] Finish at or before 2:30; never exceed the challenge's three-minute limit.

## Before publishing

- [ ] Watch the full export with sound and verify text is readable at 720p.
- [ ] Confirm no credentials, raw IP addresses, private notifications, or personal profile data appear.
- [ ] Confirm narration says approval does not apply the repair.
- [ ] Confirm the video demonstrates the deployed app, not localhost.
- [ ] Use an English title and description with the live app and repository links.
- [ ] Set visibility to **Public**, not Unlisted or Private.
- [ ] Open the YouTube URL in a signed-out/private window and play it end to end.
- [ ] Add the verified public URL to the submission checklist and Devpost draft.
